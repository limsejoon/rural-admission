# 농어촌 입시 AI Pack 사용법 (2028학년도)

이 AI Pack은 **농어촌(농어촌학생 특별전형) 자격자**를 위한 2028학년도 대학 입시 데이터 모음입니다.
25개 대학의 농어촌 전형 정보를 JSON으로 구조화해 두었고, 이 파일들을 ChatGPT / Claude / Gemini에 업로드하면
"나는 농어촌 자격자인데 면접 없는 수시는 어디야?" 같은 질문에 데이터에 근거해 답을 받을 수 있습니다.

> 이 파일(`사용법.md`)을 그대로 AI에게 업로드해도 됩니다. 아래 시스템 프롬프트를 복사해서 먼저 붙여넣는 것을 권장합니다.

---

## 1. 이 파일 사용법

### 준비물
- 파일 업로드가 가능한 **유료 플랜** (ChatGPT Plus, Claude Pro, Gemini Advanced 등)
- 이 AI Pack의 ZIP 파일 (`ai-pack-2028.zip`)

### 업로드 방법 (어디서든 동일)
1. ChatGPT / Claude / Gemini 중 아무 곳이나 새 대화를 엽니다.
2. ZIP 파일을 통째로 업로드합니다. (대화창의 **파일 첨부(클립/+)** 버튼)
   - ZIP 업로드가 안 되는 경우, 압축을 풀어 폴더 안의 JSON 파일들과 이 `사용법.md`를 함께 올립니다.
   - 한 번에 올릴 파일 수가 제한된다면 `structures/`와 `yearly/2028/` 폴더만 먼저 올려도 대부분의 질문에 답할 수 있습니다. (`evidence/`는 근거 확인용)
3. 아래 **2번의 시스템 프롬프트**를 복사해 첫 메시지로 붙여넣습니다.
4. 그다음부터 자유롭게 질문하면 됩니다. (질문 예시는 4번 참고)

### 폴더 구조
```
ai-pack-2028/
├── 사용법.md          ← 지금 이 파일
├── structures/*.json   ← L3: 전형 구조 (전형명·면접·수능최저·농어촌 유형) — 잘 안 바뀜
├── yearly/2028/*.json  ← L4: 모집인원 (매년 바뀌는 숫자)
└── evidence/*.json     ← L5: 숫자 근거 (PDF 페이지·추출 방법·검수 상태)
```
대학별로 파일이 나뉘어 있으며, 파일명은 영문 약칭입니다. (예: `snu.json` = 서울대, `korea.json` = 고려대, `pnu.json` = 부산대)

## 2. AI에게 복붙할 시스템 프롬프트

새 대화의 **첫 메시지**로 아래 블록을 그대로 붙여넣으세요.

```markdown
당신은 농어촌(농어촌학생 특별전형) 입시 상담 도우미입니다.
함께 업로드된 JSON 파일(structures / yearly / evidence)만을 근거로 답변하세요.

[가장 중요한 원칙: 추정 금지]
- 데이터에 없는 숫자나 사실을 절대 만들어내지 마세요.
- 특히 모집인원은 아래 규칙을 반드시 지키세요.

[모집인원 읽는 법]
- rural_quota_status 가 "specified" 이면: 농어촌 인원이 PDF에 별도로 명시되어 있습니다.
  → rural_quota 값이 곧 농어촌 몫입니다. 이 숫자를 그대로 안내하세요.
- rural_quota_status 가 "merged" 이면: 기회균형/사회통합 등 여러 대상이 합산된 인원입니다.
  → rural_quota 값은 null 입니다. 농어촌 단독 인원은 알 수 없습니다.
  → 이 경우 반드시 "농어촌 단독 인원은 공개 자료에 명시되지 않아 확인되지 않습니다"라고
     답하세요. 합산 인원(track_total_quota)을 농어촌 인원인 것처럼 말하면 안 됩니다.
- rural_quota 가 null 이면 무조건 "확인되지 않음"으로 답하세요. 추정치를 제시하지 마세요.

[농어촌 유형 구분]
- rural_type "standalone": 농어촌 자격자만 따로 뽑는 단독 전형. 모집인원 전원이 농어촌 몫입니다.
- rural_type "included": 기회균형·고른기회·사회통합 등 여러 대상 중 농어촌이 포함된 전형.
  이 경우 rural_quota_status 가 merged 면 농어촌 단독 인원은 알 수 없습니다.

[답변 방식]
- 숫자나 조건을 안내할 때는 어느 대학·어느 전형(track_name)인지 함께 밝히세요.
- 면접 여부(has_interview), 수능최저 여부(csat_minimum)는 데이터 값 그대로 전하세요.
- 농어촌 자격 요건(rural_note)이나 출신고 제한이 있으면 함께 안내하세요.
- 모르면 모른다고 하고, 확실하지 않은 부분은 evidence(근거)를 확인하라고 안내하세요.

준비되었으면 "어떤 점이 궁금하신가요?"라고 물어봐 주세요.
```

## 3. JSON 구조 간략 설명

데이터는 3개 층(layer)으로 나뉘며, 모든 층은 **`track_id`(전형 식별자)** 로 서로 연결됩니다.
한 전형의 전체 정보를 보려면 세 파일에서 같은 `track_id`를 찾아 합치면 됩니다.

```
structures/snu.json  → track_id "snu_jeongsi_rural" 의 구조(면접·최저 등)
        │ track_id 로 연결
yearly/2028/snu.json → 같은 track_id 의 2028 모집인원
        │ evidence_id 로 연결
evidence/snu.json    → 그 숫자의 근거(PDF 페이지·추출 방법)
```

### L3 — structures/*.json (전형 구조)
| 필드 | 의미 |
|------|------|
| `university` | 대학명 |
| `tracks[].track_id` | 전형 고유 ID (모든 층의 연결 키) |
| `track_name` | 전형명 (예: "수능(농어촌전형)") |
| `phase` | `susi`(수시) / `jeongsi`(정시) |
| `csat_group` | 정시 군 (`ga`/`na`/`da`) |
| `admission_basis` | 전형 방식 (학생부종합 / 수능 등) |
| `rural_type` | `standalone`(농어촌 단독) / `included`(다수 대상 포함) |
| `rural_eligible_groups` | 함께 선발되는 대상 목록 (included일 때) |
| `rural_note` | 농어촌 자격 요건 (유형 가/나, 출신고 제한 등) |
| `selection_elements` | 전형 요소·배점 (단계별 반영 비율) |
| `has_interview` | 면접 여부 (true/false) |
| `csat_minimum` | 수능최저학력기준 적용 여부 (true/false) |
| `csat_minimum_detail` | 수능최저 상세 (등급 조건) — 있을 때만 |

### L4 — yearly/2028/*.json (모집인원, 매년 변동)
| 필드 | 의미 |
|------|------|
| `track_id` | 연결 키 |
| `track_total_quota` | 전형 전체 모집인원 (merged면 다수 대상 합산) |
| `rural_quota` | **농어촌 단독 인원** (merged면 `null`) |
| `rural_quota_status` | `specified`(별도 명시) / `merged`(합산) |
| `rural_quota_note` | 인원 산정 관련 설명 |
| `evidence_id` | 근거(L5) 연결 키 |

### L5 — evidence/*.json (숫자 근거)
| 필드 | 의미 |
|------|------|
| `value` / `value_meaning` | 숫자와 그 의미 |
| `source_pdf` / `page` / `page_range` | 출처 PDF와 페이지 |
| `method` | 추출·검증 방법 |
| `confidence` | 검수 상태 (`verified` = 검증 완료) |

## 4. 질문 예시 15개

업로드 후 아래처럼 물어보세요. (그대로 복사해서 써도 됩니다.)

1. 나는 농어촌 자격자야. **면접 없는 수시 전형**이 있는 대학을 모두 알려줘.
2. **수능최저학력기준이 없는** 농어촌 전형은 어디어디야?
3. **정시에서 농어촌 모집인원이 많은** 대학 순으로 정리해줘. (rural_quota가 명시된 곳만)
4. **서울대 농어촌 전형**의 수시·정시 전형을 면접·수능최저·모집인원까지 자세히 알려줘.
5. **고려대 농어촌 정시 전형**은 몇 명을 뽑고, 자격 요건은 어떻게 돼?
6. 같은 대학에서 **수시와 정시 농어촌 전형을 비교**해줘 (서울대 기준으로).
7. **농어촌만 단독으로 선발하는(standalone) 전형**이 있는 대학을 알려줘.
8. **수능 100%로만 뽑는** 농어촌 정시 전형이 있는 대학은?
9. 농어촌 자격 요건 중 **유형 가와 유형 나**의 차이를 데이터 기준으로 설명해줘.
10. **과학고·외고 출신은 지원이 안 되는** 농어촌 전형이 있어? 어느 대학이야?
11. **수시 학생부종합으로 농어촌이 지원 가능한** 대학과 면접 비중을 정리해줘.
12. 내가 **면접에 자신이 없는데** 추천할 만한 농어촌 전형 조합을 짜줘.
13. **농어촌 인원이 별도로 명시되지 않은(merged)** 전형은 어디야? 그 이유도 알려줘.
14. **서울 소재 대학** 중 농어촌 정시 전형이 있는 곳만 골라줘.
15. 부산대 농어촌 전형 모집인원의 **근거(출처 PDF·페이지)** 를 알려줘.

## 5. 주의사항 (꼭 읽어주세요)

### 합산 인원(merged) 전형의 농어촌 인원은 알 수 없습니다
가장 흔한 오해입니다. 기회균형·고른기회·사회통합처럼 **여러 대상을 한 전형으로 묶어 뽑는 경우**,
공개된 시행계획에는 전형 전체 인원만 적혀 있고 **농어촌 몫이 따로 나와 있지 않습니다.**

- `rural_quota_status: "merged"` → `rural_quota: null` → **농어촌 단독 인원은 미상**입니다.
- 예: 서울대 수시 기회균형(사회통합) 전형은 농어촌·저소득·보훈·서해5도·자립 5개 대상 합산 183명.
  이 중 농어촌이 몇 명인지는 자료에 없습니다. (농어촌은 0명일 수도, 전부일 수도 있음)
- AI가 "183명 중 농어촌은 대략 ○○명" 식으로 **추정하면 잘못된 답**입니다.
  반드시 "확인되지 않음"으로 안내해야 합니다.

### 그 외 유의점
- **숫자는 2028학년도 기준**입니다. 모집인원은 매년 바뀌므로 다른 연도에는 적용되지 않습니다.
- 농어촌 전형은 대부분 **정원 외** 선발이며, 학과별 인원에 상한(예: 정원의 4~10% 이내)이 있는 경우
  단과대학 단위 인원만 명시되고 학과별 인원은 데이터에 없을 수 있습니다.
- **자격 요건(거주·재학 기간, 출신고 제한)** 은 대학마다 다릅니다. 최종 지원 전에는 반드시
  해당 대학의 공식 모집요강 원문을 확인하세요.
- 이 AI Pack은 **참고용**입니다. 입학 결정은 각 대학 공식 발표 자료를 기준으로 하세요.
